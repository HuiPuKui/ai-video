# 当年的“虾身”，长在哪儿？

横屏 1920 × 1080，24 帧/秒，总长 76 秒。第四镜末尾说“1892 年，它的化石就被当成了虾身。”第 18 秒第 8 帧切入标本桌。第 68 秒回到海里。[横屏成片](奇虾_横屏完整版.mp4) · [离线 HTML](镜头素材/三维海底预览.html) · [最初四镜构图草案](镜头素材/后半段二维分镜板.jpg)

| 镜号与全片时间 | 画面与动作 | 屏幕文案（按出现顺序） |
| --- | --- | --- |
| 05　18.33–22.50 秒 | 镜头沿着 USNM 207255 的内侧尖刺向后退，露出石板的弯曲轮廓。 | 一节接一节，虾头在哪儿？ |
| 06　22.50–27.00 秒 | 1892 年图版从石板上方铺开，推进至底部原注，铅笔在 *abdominal segments* 下方划线。 | 图注里写的是“腹节”。 |
| 07　27.00–33.50 秒 | 换到 YPM 35138 的黑白照片。放大镜从内侧的刺移向外缘关节。 | 顺着内弯看，尖刺都朝着同一侧。<br>再看外沿，一节一节的分界还在。 |
| 08　33.50–40.00 秒 | 换一块保存着弯钩的石板，用描线跟随下方轮廓。此处标本用于形态对照。 | 1979。布里格斯提出，它可能是一条附肢。<br>那它究竟连在身体哪里？ |
| 09　40.00–46.00 秒 | 在头部标本 ROM 51212 上描出左边的轮廓，揭开覆盖另一侧的薄纸，再描第二条。两处连接同时保留。 | 看头前，两边各有一条。 |
| 10　46.00–52.00 秒 | 从 ROM 51214 的头前拉到全身，孤立标本滑入右上角作对照。 | 当年的“虾身”，原来是一条前附肢。 |
| 11　52.00–60.00 秒 | 沿头部照片中标作 *ey* 的两个圆斑落圈，再到 Junnn11 的复原图上圈出对应的眼。 | 石头上这两个圆斑，就是奇虾的眼睛。<br>眼睛长在眼柄上，从头部两侧伸出去。 |
| 12　60.00–68.00 秒 | 拉开 Wawrow 的复原图，露出体侧的一排薄片，侧叶的起伏依次向后传递。运动为示意。 | 身体两侧展开的薄片，叫作侧叶。<br>游动时，侧叶依次起伏。这一波从头后传向尾端。 |
| 13　68.00–76.00 秒 | 复原切到绿色海水，从斜上方看开场的红色三维奇虾。侧叶依次划水，身体轻微起伏，从右向左游过海床。 | 侧叶推动身体，头前的附肢负责捕捉猎物。<br>如果只剩下那道弯钩，你还会把它认成一只虾吗？ |

项目原曲《知识大赏默认配乐》贯穿全片。铅笔划纸声对应第六镜的落线，头部第二条附肢出现前音乐轻压，75–76 秒渐弱。全片无人声。
