# 车都在往前开，为什么堵车却在往后走？

「vibe 知识大赏」B 站横版和抖音竖版。成片约 51 秒，每秒 24 帧。城市高架、黄车、环道和后视镜均为本片创建的三维场景，字幕直接合成到画面。音轨仅使用原项目的《知识大赏默认配乐.mp3》，从开头截取，降低音量并收尾渐弱。

## 编辑与预览

Chrome 打开 index.html 可以预览横版动画，网址末尾加 ?v 可以预览竖版。网页预览仅含画面。film.js 里的 captions 控制字幕，render 控制分镜，world.js 控制场景与车辆造型，model.js 控制车流。横竖版各有自己的相机位置和文字布局。

导出需要本机 Chrome、Python、Playwright 和可执行的 FFmpeg。将终端切到本说明所在文件夹，运行以下命令，视频与对应封面会写入 output。

```sh
python3 -m pip install playwright
python3 render.py wide output
python3 render.py vertical output
```

横封面为 1440×1080（4:3），竖封面为 1080×1440（3:4）。任一导出命令加上 `--cover-only` 即可单独重做该方向的封面。

## 实验与模型

2008 年 Sugiyama 等人的实车试验让 22 辆汽车在周长 230 米的环路上行驶。车辆密集时，微小的速度差可以被逐渐放大，拥堵区域会向车流的上游传播。[研究论文](https://doi.org/10.1088/1367-2630/10/3/033001) · [MIT 实验图解](https://math.mit.edu/traffic/)

片中高架桥使用一组相互延迟的减速、停车和加速轨迹，便于把同一波拥堵和两个固定路标相对照。环道继承实车数和环长，使用 Intelligent Driver Model 逐步演算跟车速度与车距。片中从接近均匀的初态，剪到稍后已有拥堵波的状态。环道运动是模型演示，未逐车复现原实验记录。红色路面标记表示低速，箭头分别画出车流与低速区域的传播方向。[跟车模型说明](https://traffic-simulation.de/info/info_IDM.html)
