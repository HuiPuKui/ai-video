# 第 3 集 · 小时候的暑假怎么那么长？

横版 1920×1080，竖版 1080×1920，均为 24 fps、49 秒。封面分别为 4:3、3:4 和 16:9。

## 场景与节奏

- 0 至 8 秒。老台扇、翻页台历、暑假作业和折纸船引出问题。
- 8 至 14 秒。片段 A，纸船沿重复的河岸漂流。
- 14 至 20 秒。片段 B，同样的船速与镜头运动，纸船依次遇见风筝、拱桥和荷花。
- 20 至 30.25 秒。先让观众凭印象作答，再同屏重放。两只计时器共享时间。22.75 秒开始，28.75 秒抵达 6 秒，读数保留供阅读。
- 30.25 至 40 秒。把两段画面的原始场景取景印成照片，呈现记忆里的事件分段。
- 40 至 49 秒。回到书桌，用一个问题收尾。

两段观看体验是一组叙事实例。观众的选择没有对错，成片展示了相同的客观时长。剧情围绕事后对一段经历的时长判断展开。实验研究支持记忆中可提取的事件结构与时长判断有关，人生各年龄段的长期体验还涉及其他因素。[关于事件边界的研究](https://doi.org/10.3758/s13423-025-02833-z) · [关于情境变化的研究](https://doi.org/10.7554/eLife.16070)

## 编辑与导出

Chrome 可直接打开 index.html 预览画面，添加查询参数 `?v` 预览竖版。字幕、切点与相册布置在 film.js。study.js 是暑假书桌，water.js 是两段水路，craft.js 是几何造型与材质。音频在导出时混入。配乐沿用项目提供的《知识大赏默认配乐.mp3》，没有新增人声。

需要本机安装 Chrome、Python、Playwright 和 FFmpeg。在本文件夹中执行以下命令，导出成片及对应封面。

```sh
python3 -m pip install playwright
python3 render.py wide output
python3 render.py vertical output
```

纸船、台历、风扇、桥洞、植被和相册均为本集新建的三维几何或绘制材质。相册照片来自本片场景。Three.js 与授权说明位于 lib 文件夹。配乐为用户提供的本地文件。
