# EP01《假如你玩游戏时，手机发烫每秒翻倍，会怎么样？》设计文档

## 1. 账号品牌与视觉定型（冰冷酒_ · 升级版）
- **视觉定位**：暗夜冷暖高反差 · 电影微缩感 3D 科学脑洞动画（Stylized Cinematic Diorama + PBR/Shader Volumetric Thermal Glow）。
- **固定主角 IP「小酒」**：圆润潮玩风格 3D 角色，冰青色连帽卫衣（`#38BDF8`）、灵动大眼（随热力等级切换专注/皱眉/惊恐/咬牙四种表情），与炽红/白炽手机形成最强冷暖视觉锚点。
- **双端黄金安全区画面结构（1080×1920 竖屏，兼顾 B 站 Story 流与抖音）**：
  - `Y: 8% ~ 16%`：顶栏毛玻璃双核遥测胶囊（左侧大号等宽秒表 `T = 32s`，右侧平滑跳动功率值 `215 亿瓦`，跨量级脉冲发光）。
  - `Y: 17% ~ 68%`：纯净 3D 主视觉黄金舞台（51% 画面零遮挡；关键节点在右下/中下方弹出呼吸感现实参照气泡卡片，停留约 2.5 秒自动退场）。
  - `Y: 69% ~ 76%`：单行精炼高辨识度粗体白字字幕（带关键词热橙/亮黄高亮，严格高于抖音/B站底部 20% UI 遮挡区）。
  - `Y: 78% ~ 82%`：极简黑体辐射色温能量条（左：色温状态；右：当前破坏尺度）。

## 2. 严格物理计算基准（供简介考据 & 理科生验算）
- 起点设定：大型 3D 手游高画质满载运行，手机整机发热功率 $P_0 = 5\text{ W}$。
- 翻倍公式：$P(t) = 5 \times 2^t\text{ W}$。
- 关键里程碑对照：
  - `t = 0s`：$5\text{ W}$（正常游戏微温）
  - `t = 5s`：$160\text{ W}$（约 3 台常规 50W 电暖手宝）
  - `t = 8s`：$1,280\text{ W}$（约 1 台满载家用微波炉/电烤炉）
  - `t = 13s`：$40,960\text{ W} \approx 4.1\text{ 万瓦}$（引燃被褥与宿舍家具）
  - `t = 20s`：$5.24 \times 10^6\text{ W} \approx 524\text{ 万瓦}$（局部热流堪比小型火箭发动机尾焰）
  - `t = 32s`：$2.15 \times 10^{10}\text{ W} = 215\text{ 亿瓦}$（接近三峡水电站 225 亿瓦装机满发功率）
  - `t = 42s`：$2.20 \times 10^{13}\text{ W} = 22\text{ 太瓦}$（超过全球人类实时平均总能耗 ~19 TW）
  - `t = 55s`：$1.80 \times 10^{17}\text{ W}$（超过地球接收到的全部太阳总辐射功率 $1.74 \times 10^{17}\text{ W}$）
  - `t = 60s`：$5.76 \times 10^{18}\text{ W}$（约 33 倍地球接收太阳总辐射，地表迅速熔融成岩浆球）

## 3. 五幕四尺度镜头编排
1. **开篇钩子（0~3s）**：发光白炽手机特写 → 闪切岩浆地球全屏震撼（瞬间锁住前 3 秒留存）。
2. **第一幕 · 暗夜宿舍微缩场景（0s → 13s）**：冷蓝午夜窗景 + 暖黄台灯 + 青光游戏屏，小酒窝在床头打排位；从红光热浪 → 冒烟滴液 → 被窝爆燃 + 顶灯红色火警爆闪。
3. **第二幕 · 公寓大楼破墙外景（20s）**：镜头穿透窗墙拉升至宿舍楼外立面，白炽冲击波环炸碎玻璃漫天飞溅，整栋楼烧成通红发光的熔融玻璃柱。
4. **第三幕 · 宏大 3D 城市夜景航拍（32s → 42s）**：密集发光摩天楼群夜景，宿舍点射出通天等离子火柱，巨型环形热浪横扫整座城市、建筑逐圈红化气化；镜头直冲平流层。
5. **第四幕 · 近地轨道 3D 地球 → 岩浆星球（55s → 60s）**：程序化高精地球（大陆/海洋/城市夜灯/动态云层/瑞利大气光晕），赤红热核爆发撕裂云层、蒸发海洋，最终在 GLSL 熔岩着色器下化作裂纹喷涌的岩浆星球。
6. **第五幕 · 岩浆海孤岛神反转 + 互动尾钩**：BGM 骤停，切回岩浆海中一块完好浮石，小酒举着恒星级手机大喊「别挂机，对面水晶就剩一丝血了！」，顺接「你手里的手机能撑到第几秒？评论区报型号！」。
