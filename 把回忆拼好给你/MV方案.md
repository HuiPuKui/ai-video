# 《把回忆拼好给你》MV 方案（React + SVG）

## 0. 素材分析（以下设计都基于这些实测数据）

| 项目 | 数据 |
|---|---|
| 时长 | 59.04s（抖音片段，52.5s 后人声结束，54s 起淡出，57s 静音） |
| 速度 | 约 140 BPM（一拍约 0.437s），听感是 70 BPM 的半速抒情 |
| 句长 | 每句歌词约 3.5s，也就是 8 拍、2 小节，**歌词和小节严格对齐**，适合按小节切镜头 |
| 结构 | 前奏 0–1.5s ｜ 主歌 1.5–28s（8 句）｜ 副歌 28–52.5s（7 句，高频能量明显上升）｜ 尾奏 52.5–59s |
| 角色 | 像素风 Clawd：矩形身体、两只竖条眼睛、左右两只小手、四条腿（两两一组）。主色 `#CC8B89`，高光 `#E09D9B` |
| 角色设定 | 公 Clawd = 原版；母 Clawd = 更粉的配色 + 发夹 |

**整首歌的情绪线**：渺小、灰暗 → 遇见你、世界变亮（大海）→ 你陪我、帮我驱散阴霾 → 情话像烟花，美但短暂 → 我们之间有"时差"，我骗自己放下 → 你太爱我，忘了爱你自己（苦中带甜，没有圆满结局）。

所以 MV 不能只是"甜"，最后 10 秒必须有一次情绪反转。下面三个方案都围绕这一点设计。

---

## 方案 A：《拼图》（推荐）

**核心概念**：角色本身是像素拼成的，回忆也是像素拼成的。整支 MV 就是公 Clawd 把散落的像素"回忆碎片"一块块拼起来，送给母 Clawd，片名就是这个动作。

**视觉风格**：大面积留白的米白纸张底色，16×16 网格隐约可见。所有元素（角色、海、烟花、云）都用同一套像素方块构成，没有一条曲线，靠方块的"组装 / 散开 / 重组"讲故事。色彩从灰度开始，随剧情一格一格"填色"。

**节奏设计**：每一拍落下一块像素（0.437s 一块），每小节第一拍有一次较大的"咔哒"组装和轻微镜头冲击。人声每个字出现时，对应字幕的像素字从碎片中拼出。

| 时间 | 歌词 | 画面 |
|---|---|---|
| 0–1.5 | 前奏 | 全黑。一块粉色像素在画面中心随底鼓"呼吸"闪烁两次 |
| 1.5 | 我们都是渺小真实存在 | 镜头极速拉远，那块像素原来是公 Clawd 的一只眼睛，他站在巨大灰色网格的一个角落，小到几乎看不见 |
| 5.0 | 祈愿小世界里不只有挫败 | 他试着拼一个小房子，每拍放一块，到第 8 拍整个塌掉（挫败），碎块随军鼓弹开 |
| 8.0 | 直到遇见你我以为就光明起来 | 一块粉色碎片滚到他脚边，碎片自己"站"起来，拼成母 Clawd（发夹最后一块落下，正好卡在小节重拍）。她出现的位置，灰色网格开始被染色 |
| 11.5 | 眼睛里看到的都是广袤无垠的大海 | 推镜进他的眼睛（竖条眼睛变成画框），里面的像素海浪按拍子一层层推开，铺满全屏 |
| 15.5 | 有你在的日子里不可能被取代 | 两人并排，身后不断"打印"出拼贴的回忆小方格（一起吃饭、看海、睡觉），每拍一张，像宝丽来 |
| 19.0 | 在最灰暗的日子你陪着我发呆 | 色彩退回灰度，下像素雨。两人坐着，只有她的发夹还是粉色。律动降到每两拍一次轻微晃动 |
| 22.5 | 你让我学会如何拨开阴霾 | 她伸出小手，把乌云像素一块块"拨"开，每拍拨走一块，阳光像素从缝里漏下 |
| 25.5 | 将快乐全部收集将不开心全都淘汰 | 节奏感最强的一段：两人像玩俄罗斯方块，彩色块留下，灰色块被消除，消行特效卡在每个重拍 |
| **28.0** | 你对我说的情话 | **副歌进入**。她说话时，嘴边飘出的像素字形成一串上升的小方块 |
| 31.5 | 像转瞬即逝的烟花 | 方块升到天空炸成像素烟花，炸点卡在重拍，粒子按八分音符分批散落 |
| 35.0 | 只停在绽放一刹那 | **时间冻结**：烟花粒子停在空中，画面静止 2 拍，只有他抬头的眼睛眨了一下 |
| 38.0 | 我却已无法自拔 | 他伸手想抓住空中的像素，脚下网格开始陷落，他半个身体沉进方块里 |
| 42.0 | 我们的爱总有时差 | 画面左右分屏，两人的动作错开半拍（她在正拍动，他在反拍动），永远对不上 |
| 45.0 | 也为你骗自己放下 | 他把拼好的整幅回忆画（前面所有拼贴）推给她，然后转身，自己身上的像素开始一块块脱落 |
| 48.5 | 爱炙热的你却忘了爱自己 | **反转**：镜头揭示她这一路上一直在拆自己身上的像素，补进他的世界（之前的海、阳光、烟花，用的都是她的粉色块）。她已经只剩半个身体和那只发夹 |
| 52.5–59 | 尾奏 | 他把画里的粉色块一块块取出来，按拍子拼回她身上。最后一拍，发夹归位。淡出时字幕："把回忆拼好给你" |

**为什么能拿奖**：形式和主题是一体的（像素 = 角色 = 回忆 = 歌名），结尾的反转把"忘了爱自己"这句歌词视觉化，而且前面所有画面都是伏笔，回看第二遍会发现粉色块一直在从她身上流出去。

**制作难度**：中高。核心是一套"像素粒子系统"（每个像素有起点、终点、到达拍号）。

## 方案 B：《时差》

**核心概念**：把"我们的爱总有时差"这句当成整支 MV 的结构。画面全程上下（或左右）分屏，两人生活在两个时区，一个白天一个夜晚。**用节奏本身表达时差**：她的动画永远落在正拍，他的动画永远落在反拍（延迟 1/8 拍）。

**视觉风格**：扁平几何 + 柔和渐变天空，两块屏幕的配色互补（她的一边是蜜桃色晨光，他的一边是靛蓝夜色）。中间的分割线是一条会随低频振动的细光带。

**节奏设计**：音乐每一拍都会被画面"接两次"，先她后他，形成乒乓式律动。观众会下意识觉得"差一点就对上了"，这种不适感就是叙事。

| 段落 | 画面 |
|---|---|
| 主歌前半（1.5–15.5） | 两个世界各自过日子，各自孤单。分割线偶尔透出对方的一点光（"遇见你"）。"大海"那句，两边的海平面第一次连成一条线 |
| 主歌后半（15.5–28） | 她隔着分割线陪他发呆，把自己那边的太阳推过去，帮他驱散夜色（拨开阴霾） |
| 副歌（28–42） | 他那边放烟花，她那边是白天，看不见。烟花的光只在分割线上留下一个闪光（转瞬即逝） |
| 42–48.5 | "时差"那句，节拍错位加大到半拍，两人伸手去碰分割线，总是一个刚走另一个才到 |
| 48.5–59 | 她把自己的白天全推给了他，她那边彻底变黑。最后一拍两边的动作**第一次同步**，分割线消失，但画面停在暮色里，没有完全亮起来 |

**亮点**：概念很强，评审一句话就能听懂（"用节拍差来拍时差"），很适合做成案例展示。
**风险**：分屏让画面信息密度翻倍，竖屏上会显得挤，更适合横屏。

## 方案 C：《小星球》

**核心概念**：两只 Clawd 住在一颗只有几步宽的小星球上（"渺小"、"小世界"）。星球每小节自转一格，转出一个新场景，像一本旋转的立体绘本。

**视觉风格**：等距 / 2.5D 微缩模型感，柔光、颗粒噪点、景深模糊（SVG filter 实现），偏治愈的绘本美术。

**节奏设计**：星球自转是主节拍器（每小节转 45°，用回弹缓动落在重拍）。角色的弹跳、树叶、海浪是次级律动（四分音符）。副歌加入八分音符的闪光粒子。

| 段落 | 画面 |
|---|---|
| 主歌 | 星球转出：孤独的荒地 → 她降落 → 长出花 → 转出一片海 → 下雨的那一面（两人撑一把伞发呆）→ 她吹散云 |
| 副歌 | 夜面转到正前方，烟花在星球上空炸开，影子投在星球表面上。"时差"那句，星球转太快，两人被分到明暗交界线的两侧 |
| 尾奏 | 星球慢下来，镜头拉远，原来宇宙里还有无数颗小星球。最后一颗粉色的星星靠过来 |

**亮点**：最"好看"、最容易出画面质感，商业宣传素材复用率高（每一面都可以截图当海报）。
**风险**：概念相对常见，"获奖"的辨识度不如 A 和 B。

## 三个方案对比

| | A 拼图 | B 时差 | C 小星球 |
|---|---|---|---|
| 主题契合度 | ★★★★★（与歌名直接对应） | ★★★★☆ | ★★★☆☆ |
| 创意辨识度 | ★★★★★ | ★★★★★ | ★★★☆☆ |
| 画面观赏性 | ★★★★☆ | ★★★☆☆ | ★★★★★ |
| 与像素角色的契合 | ★★★★★ | ★★★☆☆ | ★★★☆☆ |
| 实现难度 | 中高 | 中 | 高（伪 3D 和滤镜） |
| 适合画幅 | 9:16 / 16:9 都行 | 16:9 更好 | 1:1 / 9:16 |

**推荐 A**，B 的"错拍"手法可以作为 A 中 42s 那一段的技法嫁接进去（A 的表格里已经这样设计）。

## 技术方案（三个方案通用）

1. **离线节拍图**：用 librosa 预先生成 `beatmap.json`，包含每一拍、每小节重拍、onset、低频 / 高频能量曲线（每帧一个值），以及从 LRC 展开的逐字时间。动画不做实时音频分析，保证每次播放结果一致、可以逐帧精修。
2. **单一时钟驱动**：所有组件都是 `frame(t)` 的纯函数，`t` 取自 `AudioContext.currentTime`。这样不会出现音画漂移，也能直接逐帧导出成视频。
3. **导出成片**：建议用 **Remotion**（React 原生的视频框架，组件可直接复用，输出 4K / 60fps 的 MP4）。注意：Remotion 对 4 人以上的公司收费，商用前需要确认授权。
4. **角色系统**：Clawd 用 SVG `<rect>` 网格构建，开启 `shape-rendering="crispEdges"` 保持像素锐利。在网格层之上加一层骨骼（身体、手、腿、眼睛分组），统一做挤压拉伸、预备动作和跟随动画（迪士尼动画原则）。表情通过眼睛的高度和位置变化实现（眨眼、眯眼、睁大）。
5. **律动层级**：小节重拍对应镜头 / 场景切换；拍对应角色弹跳；八分音符对应粒子；低频能量对应全局微缩放；高频能量对应光效亮度。层级分开，画面才会"有呼吸"而不是全屏一起抖。
6. **字幕**：逐字卡拉 OK 式出现，与人声对齐（LRC 只有句级时间，逐字时间需要我做一遍人工校准）。
